# Sorted for Apple Music — product spec (research-backed, 24 Aug 2026)

Positioning: "My Apple Music library is a mess" → fixed in 30 seconds, on-device.
Trust line (architectural, not marketing): **we never touch your library** — read-only scan; only creates its own playlists.

## Features ↔ evidence
| Feature | User pain (signal) |
|---|---|
| Report card, instant & local, shareable | "Replay would be cool if it was accurate" (205 me-toos); stats.fm AM 3.8★ (7-day imports fail) |
| Auto genre/mood playlists, zero config | Smart playlists missing on iPhone (Miximum 524 ratings exists only for this) |
| Decade playlists 📼 | Explicit requests; iTunes had them, Apple removed them |
| Real Favorites ❤️ from play data | Favorites = "junk drawer cluttering my Library" (186 me-toos) |
| 💎 Rediscover / time capsule | SongCapsule's whole app; Marvis reviews |
| Duplicate detection + 🗑️ review queue | ">20GB of duplicates, too many to remove manually" (90+52 me-toos) |
| v1.1: refresh own playlists on re-run | Miximum's #1 complaint: exported playlists go static |
| v1.1: CSV export | 10+ export threads, zero native option |
